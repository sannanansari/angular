Pure vs Impure Pipes

Pure pipes only re-run when the input reference changes — Angular can cache the result. Impure pipes re-run on every change detection cycle, even when nothing changed. Use pure by default. Reach for impure only when you need to detect mutations inside arrays or objects.

Won't detect mutation (push). Detects new array reference.

key insight Pure pipes are memoized. The same input always returns the same output without re-running. This is why you should use immutable patterns when working with OnPush + pipes.
